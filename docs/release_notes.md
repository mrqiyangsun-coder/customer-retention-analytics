# Version 1.0.0

Portfolio release: retail analytics, five-view local dashboard and existing-customer repeat-purchase study.

Includes frozen-model evaluation over July, April and September snapshots; ten-bin reliability tables/figure; paired conditional AP-difference intervals; aggregate sensitivity to normalized within-sheet copies and signed charges; explicit dataset attribution; standalone packaging and fresh-environment verification.

Original model choices/results remain unchanged. September reliability differs from July; use scores as retrospective ranking evidence with the stated limits. No public deployment, causal marketing effect or production readiness is claimed. GitHub publication and resume insertion are separate actions from building this release.
